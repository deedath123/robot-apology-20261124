A two-line robot apology: the robot watered its owner's grandmother's orchid with yesterday's cold coffee instead of the fern beside it, and the orchid wilted overnight. It learned to read the label on every pot before pouring, so from now on it checks the tag twice and waters only the plant the tag names.

Run `python3 main.py` to write the entry to `/output/entry.txt`.
